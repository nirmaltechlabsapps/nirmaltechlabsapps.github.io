NCL Calculator - Scientific

Two calculators in one app — a full-size desktop calculator and a scientific calculator, with voice help.

NCL Calculator - Scientific is a free Android calculator that gives you both keypads in one app: a big-key desktop calculator for daily work, and a full scientific calculator with 15 built-in apps.

Get it on Google Play

Desktop calculator

  • 14-digit display, 00 and 000 keys
  • MU mark-up, TAX+ and TAX- with saved rate, GT grand total, MRC memory
  • Square root, percentage and constant (K) calculations
  • Rounding F / CUT / UP / 5-4 / ADD2, number formats including Indian 12,34,567

Scientific calculator

  • 15 apps: Equation, Table, Statistics, Matrix, Vector, Complex, Distribution, Spreadsheet, Ratio, Base-N, Convert, Function Analysis, Math Box, Catalog, Settings
  • Powers, roots, logs, factorials, nPr and nCr, trigonometry in DEG / RAD / GRAD
  • Check & Correct with up to 300 steps, and ANS CHECK

Help that explains every button

Every key is described in plain language with a real example. In scientific mode each button shows its normal function and its yellow (SHIFT) function separately, so there is no confusion. Help is available in English and Hindi, and can be read aloud.

About the app

  • Around 1 MB — installs in seconds
  • Works on Android 8.0 and above
  • Free, supported by a small number of well-spaced ads. Ads need an internet connection; the calculator works whenever you open it.
